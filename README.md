# 거북이 달려간다!

모바일 원버튼 횡스크롤 러너. 시작부터 달리고, 점점 빨라지다가 소닉 질주로 바뀝니다. 카툰(Canvas 2D)과 Three.js 화면은 같은 게임 상태를 공유합니다.

## 실행

Node.js 22.12+.

```sh
npm install
npm run dev
npm test
npm run lint
npm run build
```

휴대폰은 같은 Wi-Fi에서 개발 서버의 Network 주소로 접속합니다. 배포 파일은 `dist/`입니다.

## 조작과 규칙

- 화면을 누르는 순간 점프. 짧게 누르면 낮게, 최대 0.3초 정도 유지하면 높게 뜁니다.
- 손을 떼면 상승이 줄어듭니다. 공중에서 다시 누르면 이단 점프. 착지하면 점프 횟수가 충전됩니다.
- PC는 Space 또는 ↑를 누르고 떼면 같습니다.
- 감자·고구마, 낮은 돌, 선인장 밭, 구멍과 공중 발판이 짧은 패턴으로 이어집니다.
- 분홍 스프링은 자동으로 높이 튕깁니다. 공중 벌 아래는 낮게 점프하거나 지상으로 통과합니다.
- 코인 5개를 연속으로 먹으면 3초 터보: 최대 속도 700, 충돌 장애물 돌파. 구멍은 여전히 위험합니다. 코인 간격이 1.5초 넘거나 피해를 입으면 연속 획득이 끊깁니다.
- 목숨 3개. 장애물 충돌 시 1개 감소, 잠시 무적. 구멍 아래로 떨어지면 종료.
- 별 아이템은 6초간 자동 무적 비행. 종료 시 안전한 착륙 공간까지 비행이 연장됩니다.
- 일시정지·도움말·백그라운드 전환 시 멈춥니다. 계속하기로 재개합니다.
- 이동 거리로 최고 기록을 저장합니다. 이번 규칙은 `turtle-runner-v2-best` 키를 사용하며 이전 기록을 삭제하지 않습니다.

## 구성

- `src/game.ts`: 점프·착지·패턴·충돌·슈퍼 비행. 작은 시간 간격으로 나눠 빠른 속도에서도 충돌을 계산합니다.
- `src/motion.ts`: 달리기 → 소닉 애니메이션.
- `src/cartoon.ts`, `src/runner3d.ts`, `src/shopProps.ts`: 두 화면과 공유 장애물 그림.
- `src/main.ts`: 터치/키보드 입력, UI, 일시정지, 기록.
- `tests/game.test.ts`: 물리·규칙 테스트.
- `tests/browser.smoke.ts`: 개발 페이지에서 실행하는 입력·일시정지·화면 전환 테스트.

```js
await (await import('/tests/browser.smoke.ts')).checkRunner();
```

## 현재 범위

패턴 9종이 반복되는 첫 플레이 버전입니다. 추가 라이브러리 없이 기존 Three.js와 Canvas를 사용합니다. 3D 장애물은 2D 그림을 공간에 배치한 형태입니다. 실제 휴대폰의 터치감·성능 및 장시간 난이도는 추가 플레이 조정이 필요합니다. Three.js가 포함된 번들의 500KB 크기 안내가 남아 있습니다.
