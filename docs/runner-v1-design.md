# 거북이 원버튼 러너 1버전

## 목표

마트를 돌아다니며 부수는 현재 루프를, 조작 부담이 낮은 무한 횡스크롤 러너로 바꾼다. 플레이어는 방향을 조작하지 않고 탭으로 점프한다. 달리기 속도와 거북이의 자세 변화가 점진적 성장과 플레이 피드백을 맡는다.

## 플레이 규칙

- 거북이는 자동으로 왼쪽에서 오른쪽으로 달린다. 코스와 장애물은 진행에 맞춰 계속 생성된다.
- 탭하면 점프하고, 공중에서 탭하면 제한된 횟수까지 추가 도약한다.
- 기본 목숨은 3개다. 선인장이나 행인 같은 충돌 장애물은 목숨 1개를 깎고, 짧은 무적 시간을 준다.
- 구멍에 빠지면 즉시 라운드가 끝난다.
- 시간이 지날수록 달리기 속도를 올리고, 거북이 애니메이션을 기어가기, 이족보행, 뛰기, 전력질주, 소닉 같은 발 순으로 바꾼다.
- 아이템, 단계, 미션은 1버전에 넣지 않는다.

## 화면과 조작

기존 화면의 시작, 일시정지, 재시작, 최고기록 흐름은 유지한다. 이동 입력과 마트 파괴 UI를 러너에 맞게 바꾼다. 마트 배경 요소를 장애물과 발판으로 재사용할 수 있는지는 렌더러 구현을 확인하며 정한다.

## 확인이 필요한 기본값

추가 도약 횟수, 속도 증가 곡선, 목숨 손실 후 무적 시간은 구현 중 조정 가능한 초기값으로 둔다. 점프 입력이 복잡해지지 않도록 탭 한 번당 도약 한 번으로 처리한다.
