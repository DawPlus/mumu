# 다음에 이어서 하기

## 현재 상태

현재 구현은 **「거북이, 사고쳤다!」**: 30초 동안 거북이를 드래그로 움직여 마트를 부수는 모바일 웹 게임.

- 카툰(Canvas 2D) / 장난감 3D(Three.js) 전환.
- 캔 → 상자 → 진열대 → 냉장고 순으로 성장·파괴.
- 콤보, 점수, 최고 기록 저장, 재시작, 일시정지, 효과음.
- Vite + TypeScript. React/Expo 프로젝트가 아님.

## 가장 중요한 사용자 피드백

**“이것도 좀 노잼인딩 ㅋㅋㅋ 아 뭐없나” → “그래도 귀엽긴해ㅋ”**

귀여운 캐릭터·그림체는 긍정적. 게임의 재미는 아직 만족하지 못함. 현재 버전을 완성된 재미의 기준으로 취급하지 말 것.

이전에 주차 타이밍 게임 → 방해꾼을 응원단으로 변경 → 빠른 무한 브레이크 게임 → 현재 마트 파괴 게임을 시도했음. 반복 작업이나 기다림 위주의 플레이가 잘 맞지 않았음.

마지막으로 한 손가락 밀치기(상대 AI와 원형 경기장 생존), 줄로 공 튕기기, 야바위 속임수 잡기를 아이디어로 제안했지만 **어느 것도 구현 승인받지 않았음**. 사용자가 “한 판만 더” 하게 되는 기존 게임 취향도 아직 확인되지 않음. 다음에는 캐릭터를 살리면서 새로운 핵심 재미를 함께 정하면 됨.

## 실행 및 확인

```sh
npm ci
npm run dev
npm test
npm run lint
npm run typecheck
npm run build
```

- `src/game.ts`: 이동·충돌·성장·타이머·물건 배치.
- `src/cartoon.ts`, `src/toy.ts`: 두 렌더러.
- `src/main.ts`, `src/style.css`: 입력·화면·기록·결과창.
- `tests/browser.smoke.ts`: 개발 서버 페이지에서 호출하는 실제 UI 테스트.
- `docs/design.md`: 과거 실험과 검증 기록. 상단 최신 설계만 현재 요구사항임.

## 검증과 남은 한계

업로드 전 단위 테스트 11개·lint·타입 검사·프로덕션 빌드 통과. 카툰/3D 모두 브라우저에서 30초 플레이·최대 성장·재시작·기록 저장·작은 화면을 확인함. 낮은 프레임에서도 실제 30초를 지키도록 수정했고 일시정지 중 렌더링도 중단함.

실제 폰의 손맛·성능은 미확인. 물리 연출은 가벼운 직접 계산 방식. 핵심 미해결점은 **기술적 작동이 아니라 재미**임. 외부 배포는 하지 않았음.
