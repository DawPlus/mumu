# 다음 작업 메모 — 2026-11-19

현재 게임은 마트 파괴가 아닌 원버튼 횡스크롤 러너입니다.

## 사용자 요청을 반영한 최신 변경

- 시작부터 달리기, 약 12초부터 소닉 자세. 속도 420 → 최대 600.
- 누르는 즉시 점프, 유지 시간에 따라 높이 조절, 놓으면 상승 감소. 이단 점프 유지.
- 감자·고구마·낮은 돌·선인장 밭·구멍·공중 발판으로 패턴 구성.
- 발판은 내려올 때 착지하고 점프 충전. 지면 없는 구간은 발판을 연결해 통과.
- 별 획득 시 6초 무적 자동 비행. 종료 후 안전한 땅으로 착륙.
- 카툰과 3D 모두 같은 상태 사용. 모바일 입력 취소, 도움말, 백그라운드 일시정지 지원.

## 이어서 볼 점

캐릭터의 귀여움은 유지하고 실제 재미·점프 손맛을 사용자가 플레이하며 조정할 단계입니다. 패턴은 현재 9종 반복. 분홍 스프링 자동 도약, 높은 점프를 방해하는 벌, 코인 5연속 → 3초 터보(최대 700, 장애물 돌파·구멍은 위험), 두 모드의 속도선/전경 흐름이 추가됨. 실제 휴대폰 검증과 난이도 튜닝이 남아 있습니다. 구현/검증 명령은 README 참조. 기존 docs/design.md와 runner-v1-design.md는 이전 버전의 기록입니다.
